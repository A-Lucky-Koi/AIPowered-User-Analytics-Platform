# 验收记录

日期：2026-11-09（Asia/Shanghai）。环境：Windows，Python 3.10.10，Node 24.19.0 仅作语法检查；浏览器为 Codex 内置 Chromium。运行时无需 Node。

## 自动测试

执行 `python -m unittest discover -s tests -v`：**18 个测试全部通过**。

- DAU / WAU 去重、MAU 历史不足、付费率与 ARPU、封禁排除、回流 7 天边界。
- 留存未成熟与加权/算术平均差异、漏斗单调、LTV 成熟分母。
- 超出观测范围的指标为 null，而不是伪造零值。
- 服务端渠道范围不可由请求覆盖、运营付费结果置空、分群标识脱敏。
- 告警确认按账号隔离；同一渠道范围的两个账号不会共享处理状态。
- SQL 沙箱的表/函数白名单、写入/多语句/文件访问拒绝、行数上限、昂贵查询熔断。
- CSV 数值/日期/字段校验、失败不改变事实、重复导入 UPSERT、维度冲突拒绝、首个真实批次替换演示事实。
- 任意表头顺序下的尾部缺值返回带行号的校验错误，不会升级为服务器错误。
- HTTP 首次 setup、密码长度、已存在账号保护、登录/退出、会话 Cookie、CSRF、Origin、未登录与无权限拒绝。
- 收藏按账号隔离、AI 返回 501 + enabled:false。
- 静态路径边界，数据库与源码不能从 Web 路径下载。

`python -m py_compile server.py data.py` 与 `node --check web/app.js` 通过。

## 浏览器验收

使用独立 `.qa/preview.db` 与测试账号，不创建或占用正式管理员。

- 登录、总览卡片、趋势与设备图渲染。
- 留存热力表显示成熟值与 “—”，曲线可见。
- SQL Lab 默认查询返回 14 行，按日期倒序，数值与大盘一致。
- AI 侧栏建议问题可填入；“检查接入”明确返回未配置，没有伪造回复。
- 用户分群默认条件命中 3,827 人，显示前 100 行脱敏预览。
- 系统数据接入页显示 16,038 用户、136,914 日事实、450 费用记录。
- 六步骤漏斗计数递减，转化率与流失值可查看。
- 渠道表/象限/新增图渲染；自然流量费用为零时 ROAS 为 “—”。
- 选择 TapTap 并应用筛选后，渠道表仅一行；结束日日活 493、流水 ¥1,168、付费率 3.85%。
- 收藏筛选，返回工作台可见；打开收藏后页面与渠道条件恢复。
- 管理员写入 SQL 与新账号密码草稿后退出；重新登录时 SQL 恢复默认，新账号密码为空，跨账号状态未残留。
- 图表“查看数据”使用可识别的列标题，浏览器可访问树能够读取日期、活跃设备、新增设备和流水表头。
- 桌面布局及 390 × 844 窄屏：文档宽度不超过视口，移动菜单可打开与关闭，留存表在自身容器内横向滚动。
- 验收时控制台未出现渲染错误。修复了无构建 DOM 模板中自闭合 Vue 组件导致文本被吞的问题，以及移动卡片环比换行。

## 性能观察

单机演示库约 13.7 万条事实，默认 14 日全模块聚合调用一次约 **1.9 秒**（本机一次测量，非并发压测；不包含静态资源下载）。本地数据量下可交互，尚不构成首屏 ≤2s 或下钻 ≤5s 的性能保证。长范围或多用户查询需进一步预聚合、分页、缓存与负载测试。
